System Philosophy & Safety Directives

1. Core Design Principles

Why standard machine learning alone is insufficient for life-safety mountain corridor operations
Foundational Axioms
🎯
Backend as Single Source of Truth
The frontend never computes risk scores, probability thresholds, or escalations. It strictly acts as a rendering and telemetry interaction layer against the FastAPI backend service.
  • Zero Client Drift: All thresholding logic and safety policy resides strictly in backend services.
  • Auditable Traceability: Every returned assessment includes complete calculation provenance.
⚖️
Policy Separated from Statistical Prediction
The system decouples statistical ML predictions (inference_service) from operational policy decisions (risk_engine).
  • Independent Levels: Both model_risk_level and final_risk_level are returned separately.
  • Observable Escalation: Operators always see if an engineering rule overrode the model.
🛡️
Fail Safe, Not Silent
When critical sensor observations (temperature, slope) are missing or corrupt:
  • The engine returns INSUFFICIENT_DATA rather than fabricating a plausible default.
  • Out-of-bound sensor inputs are nulled with recorded warnings, never silently clamped.
⏳
Strict Temporal & Spatial Isolation
All time-series rolling features enforce T_obs ≤ T_target to completely eliminate future look-ahead data leakage.
  • Physical Spatial Interpolation: Physical weather variables are interpolated across grid coordinates first; models execute per-cell rather than averaging risk scores.

Rejects physically impossible environmental sensor telemetry:

Layer 3: Geospatial Intelligence & Interpolation

5. Spatial Layer & Physical Interpolation

Why we interpolate physical atmospheric features, not output probabilities
ml/spatial/idw.py
🗺️
Inverse Distance Weighting (IDW) of Physical Fields

Crucial Architectural Decision:

Physical variables (temperature, SWE, precipitation, new snowfall) are interpolated over the 2D/3D coordinate grid using Haversine distance weighting (power = 2.0). The machine learning model is subsequently executed independently on every grid cell.

Anti-Pattern Avoided: Interpolating risk probabilities directly across space would artificially smooth out sharp ridgelines, convex rolls, and couloir release zones.
📊
Spatial Validation & Denial-of-Service Limits
  • Leave-One-Station-Out (LOSO) CV: Measures spatial generalization error (RMSE, MAE) across isolated stations.
  • Uncertainty Quantification: Calculates station distance penalty and sparse-station variance.
  • Computation Guardrails:
    • Max bounding box: 1.5° × 1.5°
    • Max grid cells: 625 cells
    • Requests exceeding limits return 422 Unprocessable.
Layer 4: Supervised Learning & Calibration

6. Calibrated Machine Learning Pipeline

Probability calibration (CalibratedClassifierCV) and threshold optimization
api/services/inference_service.py
Supervised Ensemble Models
Trained on historical CAIC observations & high-altitude weather records:
  • Primary: Calibrated Random Forest Classifier
  • Benchmarked: Gradient Boosting, XGBoost, CatBoost, Regularized Logistic Regression
  • Class Weighting: Balanced penalization to address extreme rarity of avalanche release events.
Probability Calibration
Raw tree predictions are uncalibrated and overconfident:
  • CalibratedClassifierCV: Isotonic & Sigmoid post-processing transforms raw margins into authentic release probabilities.
  • Brier Score Minimization: Ensures that when the system predicts 70% risk, the historical event rate matches 70%.
Safety-Tuned Thresholds
Standard 0.50 threshold is dangerous in life-safety domains:
p < 0.40LOW RISK
0.40 ≤ p < 0.70MEDIUM RISK
p ≥ 0.70HIGH RISK
Optimized for high recall over dangerous false negatives.
Layer 5: Policy & Safety Ratchet

7. Deterministic Safety-Critical Risk Engine

A strict, auditable, one-way upward escalation policy layer
ml/risk_engine.py
🛡️
3-Stage Evaluation Architecture
  1. Stage 1: Data Quality Assessment
    Checks presence of critical features (temperature, slope). If missing → returns INSUFFICIENT_DATA.
  2. Stage 2: Statistical Base Mapping
    Maps calibrated probability p into initial base score & level.
  3. Stage 3: Deterministic Physical Escalations
    Evaluates physical laws. Escalations are strictly one-directional (ratchet up, never down).
⚡
Deterministic Escalation Rules
Rule 1: Heavy Storm Loading (Snowfall 24h ≥ 30mm OR 72h ≥ 45mm) AND Slope ≥ 34° → Forces HIGH RISK (≥ 70%)
Rule 2: Rapid Thermal Warming Temp 24h delta ≥ +5°C AND Temp > 0°C AND Slope ≥ 30° → Forces MEDIUM/HIGH
Rule 3: Wind Slab Loading Max wind ≥ 40 km/h AND Snowfall 24h ≥ 10mm AND Slope ≥ 32° → Escalates Risk
